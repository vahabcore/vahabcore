## ⚙️ Core Capabilities & Architecture
Instead of just writing code, I focus on engineering comprehensive systems. My technical footprint spans across several core architectural domains:

* **Distributed Systems & Event-Driven Backends:** I architect highly scalable infrastructures capable of processing massive daily event volumes. By leveraging tools like Fastify, MongoDB Change Streams, and Redis (BullMQ), I build systems with guaranteed event delivery, batch processing, and automated retries via Dead Letter Queues (DLQs).
* **Ultra-Low Latency & Real-Time Communication:** I specialize in engineering cross-platform, bi-directional communication systems. Utilizing WebRTC, Socket.io, Tauri, and Rust, I build secure, high-concurrency environments that achieve sub-30ms latency for applications like remote desktop control and real-time synchronization.
* **Sovereign Data & Offline-First Software:** I design privacy-first desktop solutions capable of complex, localized data processing—such as financial calculation engines and PDF parsing—ensuring strict data integrity without reliance on external cloud dependencies.
* **High-Performance Consumer Platforms:** I have extensive experience architecting and scaling consumer-facing web platforms optimized for sub-second load times, dynamic SEO strategies, and the ability to seamlessly handle tens of thousands of monthly active users.
