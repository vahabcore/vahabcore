## About Me
* I'm a full-stack expert heavily utilizing JavaScript, TypeScript, Node.js, Next.js, and React.
* As a Solo Founder, I am actively building my own venture with the long-term vision of scaling it into a highly successful, large-scale business.
* I am currently engineering TruLedger, an offline-first desktop software toolkit tailored for Chartered Accountants. It is intentionally built to function entirely without cloud dependency to ensure strict financial data privacy, featuring automated GST validators and complex PDF-to-Excel engines.
* I also architected, manage, and scale a B2C platform, shaadibiodata.in, successfully handling over 10,000 monthly active users with sub-second load times for optimal monetization.
* I am deeply interested in AI agent development and utilizing LLMs to optimize workflows, create context-aware applications, and drive SEO strategies.
* I value modern, high-end visual web aesthetics and recently pushed my front-end boundaries with an interactive Cyber-Matrix 3D project submission for the Google I/O Countdown challenge.

## Software Engineer & Architect
In my professional career at MeltX Software Solutions, I focus on building highly reliable and high-throughput backend infrastructure.
* **Microservices & Event-Driven Systems:** I architected a highly scalable Patch Management System processing 10,000+ daily events using Fastify. I also built the Global Search Worker using MongoDB Change Streams and Redis (BullMQ) to handle batch processing at 500+ jobs/sec with 100% event delivery via Dead Letter Queues.
* **Low-Latency Architecture:** Engineered ControlX, an internal Remote Management System utilizing Tauri, React, WebRTC, and Rust to achieve ultra-low latency (<30ms) for secure, real-time screen sharing and remote desktop control.
* **Data Consistency:** Designed the backend architecture for the Physical Asset Verification (PAV) Module, enforcing strict data integrity and utilizing comprehensive E2E testing to seamlessly handle asset tracking.
